# scratch-playground
---
Este repositório centraliza meus projetos e experimentos feitos no *Scratch*, uma plataforma visual criada pelo MIT para ensinar lógica de programação de maneira simples, divertida e totalmente interativa.

_*Trabalho aqui conceitos fundamentais de desenvolvimento, como fluxo lógico, eventos, condições, loops e animação — tudo usando blocos que se encaixam como peças de um jogo. Esse ambiente me ajuda a testar ideias rapidamente e fortalecer minha base de raciocínio para linguagens mais avançadas.*_

Você pode explorar e criar seus próprios projetos no site oficial:
🔗 https://scratch.mit.edu/
