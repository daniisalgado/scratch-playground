## 📖 Sobre o Projeto

Bem-vindo ao meu **Laboratório de Lógica**! 🚀

Este repositório centraliza meus projetos e experimentos desenvolvidos no **Scratch**, a plataforma visual criada pelo MIT. Aqui, o foco não é apenas "arrastar blocos", mas sim compreender a engenharia por trás do código.

Utilizo este espaço para transformar ideias abstratas em interações visuais, solidificando minha compreensão sobre como os computadores pensam e executam tarefas.

---

## 🧠 O que estou explorando?

Embora o visual seja lúdico, os conceitos aplicados aqui são a base para qualquer linguagem de programação avançada (como JavaScript, Python ou C#). Neste playground, foco em dominar:

* **🧩 Algoritmos e Lógica:** Estruturação passo-a-passo de soluções.
* **🔀 Fluxo de Controle:** Uso de condicionais (`if`, `else`) e loops (`repeat`, `forever`).
* **🎮 Eventos e Interatividade:** Como o programa reage ao usuário (teclado, mouse, cliques).
* **🎨 Animação e Coordenadas:** Manipulação de objetos no plano cartesiano (X, Y).
* **📦 Variáveis e Operadores:** Armazenamento de dados e cálculos matemáticos em tempo real.

---

## 💡 Por que Scratch?

> _"Trabalho aqui conceitos fundamentais de desenvolvimento, como fluxo lógico, eventos, condições, loops e animação — tudo usando blocos que se encaixam como peças de um jogo. Esse ambiente me ajuda a testar ideias rapidamente e fortalecer minha base de raciocínio para linguagens mais avançadas."_

É o meu ambiente de **prototipagem rápida** e **treino de lógica pura**, sem a preocupação inicial com erros de sintaxe.
